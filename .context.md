# TabBellus Project Context Manifest
**Project Version:** 1.2.2

## 1. Database Schema (Dexie.js)
**Database Name:** `TabBellusDB` (Version 3)

### Tables & Indexes
- **`spaces`**: `++id, name, createdAt, deletedAt`
  - `name` (string): User-provided space label.
  - `createdAt` (timestamp): Creation date.
  - `deletedAt` (timestamp, optional): Soft-delete marker.
  - `isPinned` (boolean, optional): User favorite status for 4-tier sorting.
  - `color` (string, optional): Chrome tab group color tag token.
- **`tabs`**: `++id, spaceId, url, order, [spaceId+order]`
  - `spaceId` (number): FK to `spaces`.
  - `url` (string): Full browser URL.
  - `title` (string, optional): Tab title captured at the time.
  - `favicon` (string, optional): Captured icon URL.
  - `order` (number): Relative position in the space.
- **`readLater`**: `++id, url, addedAt, status`
  - `status`: `'unread' | 'read' | 'archived'`

## 2. Core Services
Located in `src/lib/`.

- **`db.ts`** (`TabBellusDB`):
  - `spaces`: `++id, name, createdAt, deletedAt`
  - `tabs`: `++id, spaceId, url, order, [spaceId+order]`
  - `readLater`: `++id, url, title, addedAt, status`
    - `status`: `'unread' | 'read' | 'archived'`
  - **Shared Types**: Exports `SpaceWithTabs` and `SavedTabResult` for data transfer boundary safety.

### **SpaceService**
- `captureCurrentWindow(spaceName)`: Validates current window tabs, filters internal `chrome://` URLs, and performs an atomic transaction to save `Space` and related `Tabs` records.
- `addTabToSpace(spaceId, tab)`: Adds tab to space with duplicate URL checking within target space (throws `DUPLICATE_TAB` error on duplicate URL).
- `createEmptySpace(spaceName)`: Atomically inserts a new empty `Space` into Dexie without capturing current window tabs, separating modal creation from active session captures.
- `restoreSpace(spaceId)`: Fetches ordered tabs and opens them in a new focused Chrome window with staggered loading (tab storm prevention). Wraps `chrome.sidePanel.open` in try/catch and uses declarative `chrome.sidePanel.setOptions` to safely handle gesture token expirations. Emits a decoupled restore event to listeners.
- `createSpaceFromTabs(name, tabs)`: Low-level atomic creation of a Space from an explicit list of tabs. Handles fallback naming for unnamed groups.
- `duplicateSpace(spaceId)`: Atomically duplicates a Space and its tabs into "Copy of [Name]" preserving relative tab order.
- `moveTabBetweenSpaces(tabId, targetSpaceId)`: Atomically moves a tab to a target space with duplicate URL prevention, appending to highest order index and returning original position metadata.
- `copyTabToSpace(tabId, targetSpaceId)`: Atomically clones a tab to a target space with duplicate URL prevention at highest order index.
- `updateSpaceDetails(spaceId, name, color)`: Atomically updates space name and color metadata in IndexedDB.
- `updateSpaceColor(spaceId, color)`: Updates space color token metadata in IndexedDB.
- `updateSpaceName(id, newName)`: Updates space name in IndexedDB.
- `toggleSpacePin(spaceId)`: Toggles user pinned status on a space for priority sorting.
- `getTabsForSpace(spaceId)`: Fetches sorted tab records for a space from Dexie.
- `appendSpaceTabsToWindow(spaceId, windowId)`: Safely appends a space's tabs into an existing Chrome window ID with staggered loading, deduplicating against currently open window URLs and returning typed telemetry (`AppendTabsResult: { total, appended, skipped }`).
- **Database Boundary Encapsulation**: Exposes query providers (`getSpacesOrderedQuery`, `getSpacesNewestFirstQuery`, `getSpaceByIdQuery`, `getTabsForSpaceQuery`, `getSpacesWithTabsQuery`) and CRUD helpers (`softDeleteSpace`, `undoDeleteSpace`, `hardDeleteSpace`, `getSpaceById`, `getTabById`, `deleteTab`, `restoreTab`, `restoreTabPosition`) to prevent raw database queries or engine handles from leaking into the UI.

### **BookmarkService** (`src/lib/bookmarkService.ts`)
- `getBookmarkTree()`: Safely wraps `chrome.bookmarks.getTree()` with try/catch fallback to return the browser bookmark hierarchy.

### **TabService** (`src/lib/tabService.ts`)
- `focusOrCreate(url)`: Normalizes URLs and checks all open tabs across all windows. If a matching URL is found, focuses the target tab and its parent window via `chrome.windows.update` and returns typed telemetry `{ action: 'focused', tabId, windowId }`; otherwise creates a new tab and returns `{ action: 'created', tabId, windowId }`.
- `calculateDuplicates(tabs)`: Identifies duplicate tabs by normalized URL, prioritizing Pinned > Active > Lowest Index.
- `getTabZoom(tabId)` / `setTabZoom(tabId, zoomFactor)`: Queries and adjusts tab zoom factor clamped between 0.25 and 5.0.

### **ReadLaterService**
- `addFromTab(tab)`: Saves tab to Read Later database with URL deduplication checking.
- `updateStatus(id, status)`: Updates status of a Read Later item.
- `getDistinctDomains(status)`: Computes sorted unique hostnames from items matching a given status. Safely skips malformed URLs.
- `archiveAllUnread()`: Transitions all unread items to `'archived'` status inside an atomic `db.transaction`.
- `clearAllArchived()`: Deletes all items with `status === 'archived'` inside an atomic `db.transaction`.
- `migrateGhostStatesToArchive()`: Atomic startup helper migrating orphaned items where `status === 'read'` to `status === 'archived'`, unblocking URL re-addition under the binary state machine.
- **Database Boundary Encapsulation**: Exposes query providers (`getItemsByStatusQuery`, `getUnreadCountQuery`) and CRUD/lifecycle helpers (`getItemById`, `deleteItem`, `restoreItem`, `getAllItems`) to ensure zero IndexedDB engine leakage into view components.

### **SessionUtils**
- `getRecentSessionId(maxRetries)`: Polling utility with retry backoff to reliably capture recently closed session IDs.
- **Unified Fuzzy Matching Rules**: Exposes `isValidUrl`, `tryParseHost`, and `isFuzzyMatch` to centralize URL validation and fuzzy matching rules for matching closed windows to spaces in both `HistoryDialog.tsx` and the background script.
- **Unit Tests**: Covered by `src/lib/__tests__/sessionUtils.test.ts` (Vitest) to verify subdomains, path suffixes, and SPA route matches.

### **Color Utility**
- **`colors.ts`**: Maps `chrome.tabGroups.ColorEnum` constants to a structured palette including `badge` (solid), `row` (tint), and `border` (guide line) classes for UI consistency.

### **Platform Utility**
- **`platform.ts`**: Browser detection (`isEdge`), OS detection (`isMac`, `getOS`), dynamic keybinding formatting (`formatKeyBinding`, `getReadLaterShortcutText`), safe external link handling (`handleExternalLink`), and `openSupportHub` (extends link with version/browser params).
- **`config/links.ts`**: Centralized `EXTERNAL_LINKS` including Support Hub and Ko-fi.

### **DataService**
- **`dataService.ts`**: Backup & Restore utility.
  - `exportData()`: Downloads all spaces/tabs/read-later as JSON.
  - `exportSpaceAsJson(spaceId)`: Downloads a single space and its tabs as JSON.
  - `importData(file)`: Parses backup, creates new Spaces, maps old IDs to new ones to preserve Tab relationships, and imports data.
  - `clearData()`: Clears all tables.

### **Date Utility** (`src/lib/dateUtils.ts`)
- `formatRelativeTime(timestamp)`: Formats timestamps into human-readable relative time strings (e.g., "now", "5 minutes ago", "yesterday", "2 weeks ago", "last month", "2 years ago") using native `Intl.RelativeTimeFormat`.
- `isStale(timestamp, daysThreshold)`: Determines if an item is older than the configured staleness threshold (default: 30 days).
- `normalizeTimestamp(timestamp)`: Normalizes `Date`, `string`, or `number` values into Unix epoch milliseconds.

### **Hooks**
- **`useUndoDelete`** (`src/hooks/useUndoDelete.ts`): Reusable hook for deleting items with "Undo" toast. Decoupled from database engines via functional callback configuration (fetch/delete/restore).
- **`useClipboard`** (`src/hooks/useClipboard.ts`): Hook for copying text with temporary success state.
- **`useIsTruncated`** (`src/hooks/useIsTruncated.ts`): Generic hook using `ResizeObserver` to detect CSS text truncation. Used by `SpaceItem`, `TabRow`, and `GroupRow` for conditional hover tooltips.
- **`useCurrentSpace`** (`src/hooks/useCurrentSpace.ts`): Hook to fetch the currently active `Space` associated with the active window by combining `useAppStore`'s `activeSpaces` mapping and Dexie's live query.
- **`useAddToSpaceAction`** (`src/features/spaces/hooks/useAddToSpaceAction.ts`): Reusable hook to handle space loading and atomic tab additions to spaces, utilized by both hover buttons and context submenus.
- **`useTabLifecycle`** (`src/features/tabs/hooks/useTabLifecycle.ts`): Subscribes to Chrome tab events (`onCreated`, `onUpdated` including `discarded` tab suspension state, `onRemoved`, `onMoved`, `onActivated`, `onAttached`, `onDetached`, `onReplaced`).
- **`useGroupLifecycle`** (`src/features/tabs/hooks/useGroupLifecycle.ts`): Subscribes to Chrome tab group events (`onCreated`, `onUpdated`, `onRemoved`, `onMoved`).

### **UI Primitives**
- **`Toaster`** (`src/components/ui/Toaster.tsx`): Custom toast notification system supporting action undo handlers (`onUndo`) and educational subtitles (`description?: string`).
- **`Tooltip`** (`src/components/ui/Tooltip.tsx`): Radix Tooltip wrappers. Defines `TooltipSimple` (general hover description) and `TooltipOverflow` (truncation-triggered hover details) to encapsulate boilerplate composition.
- **`SmartFallbackIcon`** (`src/components/ui/SmartFallbackIcon.tsx`): Context-aware fallback icon component resolving URL schemes to specific Lucide icons (`chrome://extensions` → Puzzle, `chrome://settings` → Settings, `chrome://`/`edge://` → AppWindow, `file://*.pdf` → FileText, `file://*` → File, Default → Globe).
- **`ContextMenu`** (`src/components/ui/context-menu.tsx`): Radix Context Menu wrappers matching Sleek Developer Minimalist tokens.
- **`Dialog`** (`src/components/ui/Dialog.tsx`): Radix Dialog modal wrapper for empty space creation and settings.
- **`Popover`** (`src/components/ui/popover.tsx`): Radix Popover wrapper for the read-only Global Bookmarks popover.

## 3. MANDATORY CUSTOM ABSTRACTIONS
To prevent context amnesia, code duplication, and inconsistent UI patterns, developers and AI agents MUST strictly use these established project abstractions instead of native browser fallbacks or raw primitives:

### **1. User Feedback & Notifications (`useToast`)**
- **STRICT RULE:** NEVER use native `alert()`, `confirm()`, or raw unstyled inline error text for user notifications. ALWAYS use `const { toast } = useToast()` from `@/components/ui/Toaster`.

### **2. Clipboard Management (`useClipboard`)**
- **STRICT RULE:** NEVER invoke `navigator.clipboard.writeText()` directly inside components. ALWAYS use `const { copy } = useClipboard()` from `@/hooks/useClipboard` to ensure automated temporary success states and consistent error handling.

### **3. Tab & List Row Items (`InteractiveRow`)**
- **STRICT RULE:** NEVER build custom list item rows or flex containers from raw `<div>` elements for tab or space listings. ALWAYS use the `<InteractiveRow>` compound component primitive (`<InteractiveRow.Leading>`, `<InteractiveRow.Title>`, `<InteractiveRow.Actions>`, `<InteractiveRow.Action>`) from `@/features/tabs/components/InteractiveRow`.

### **4. Favicons & Icon Fallbacks (`SmartFallbackIcon`)**
- **STRICT RULE:** NEVER render unhandled raw `<img>` icons for website favicons. ALWAYS pair favicon images with `<SmartFallbackIcon url={url}>` from `@/components/ui/SmartFallbackIcon` to guarantee smooth domain letter or globe fallbacks on broken/missing icons.

### **5. Tooltips & Text Truncation (`TooltipSimple` & `TooltipOverflow`)**
- **STRICT RULE:** NEVER use native HTML `title="..."` attributes on main text elements or raw Radix tooltip boilerplates directly. ALWAYS use `<TooltipSimple content="...">` from `@/components/ui/Tooltip` for action buttons and `<TooltipOverflow text="..." isTruncated={...}>` (paired with `useIsTruncated`) for truncated titles.

### **6. Context & Dropdown Menus (`ContextMenu` & `DropdownMenu`)**
- **STRICT RULE:** NEVER build custom fixed-position context menu divs or raw browser context listeners. ALWAYS use the styled Radix UI primitives (`<ContextMenu>`, `<ContextMenuContent>`, `<ContextMenuItem>`) from `@/components/ui/context-menu` or `@/components/ui/dropdown-menu`.

### **7. Database Queries & Domain Encapsulation (`spaceService`, `tabService`, `readLaterService`)**
- **STRICT RULE:** NEVER write raw Dexie queries (`db.spaces.where(...)`, `db.tabs.bulkAdd(...)`) directly inside React UI components. ALWAYS consume encapsulated query providers and CRUD methods from `spaceService`, `tabService`, `readLaterService`, or `dataService` in `@/lib/`.

### **8. Destructive Actions & Deletions (`useUndoDelete`)**
- **STRICT RULE:** NEVER perform immediate irreversible deletions in UI components without offering an undo opportunity. ALWAYS wrap destructive delete actions with `useUndoDelete()` from `@/hooks/useUndoDelete` to present toast notifications with `onUndo` restoration hooks.

### **9. External Links & Platform Compatibility (`platform.ts`)**
- **STRICT RULE:** NEVER call raw `window.open` or unvalidated `chrome.tabs.create` for support or setting links. ALWAYS use `handleExternalLink()`, `openAppearanceSettings()`, or `openSupportHub()` from `@/lib/platform.ts` to ensure cross-browser compatibility (Chrome vs. Edge) and diagnostic parameters.

## 5. State Management
- **Zustand (`useAppStore`):**
  - Persistence: Persisted to **Chrome Storage Local** using a custom adapter.
  - Theme Management: Implemented in `src/sidepanel/index.tsx` via `useEffect` to sync selected theme ('light'|'dark'|'system') with `document.documentElement`. When `system` is active, it binds a native `change` event listener on `window.matchMedia('(prefers-color-scheme: dark)')` with automated unmount cleanup to update themes reactively in real time.
  - Data: UI state like `activeView` and hydration status.
  - **Active Spaces Bridge:** `activeSpaces` (ephemeral) maps `SpaceID -> WindowID` for tracking open spaces. Enforces strict 1-to-1 Window-to-Space binding by removing existing space mappings for a target `windowId` before registering a new space. Synced across windows via `chrome.storage.session`. Subscribes to `spaceService.onRestore` events to dynamically register active spaces upon restoration.
- **Zustand (`useTabLockStore` - `src/features/tabs/store/tabLockStore.ts`):**
  - Ephemeral tab protection store managing `lockedTabIds: number[]`.
  - Persistence: Continuously synchronized with `chrome.storage.session` and subscribed to `chrome.storage.onChanged` for instant cross-window UI updates.
  - **Content Script (`src/content/lockGuard.ts`):** Registered in `manifest.config.ts` under `content_scripts` for `<all_urls>`. Intercepts `beforeunload` events and hard navigation link clicks on locked tabs, ignoring `#` anchors, `javascript:`, and `mailto:` links to maintain SPA integrity.
- **Background Worker (`src/background/index.ts`):** Listens to tab updates (`onCreated`, `onUpdated`, `onMoved`, `onAttached`, `onDetached`, `onReplaced`, etc.) and debounces updates to IndexedDB continuously when the active window corresponds to a known tracked space. Uses `chrome.alarms` for background sync flushing (`sync-flush-${windowId}`). Performs 1-to-1 Best Match fingerprinting on startup (`auditActiveSpacesOnStartup`), ranking spaces by score/coverage and tab length differences so the single highest-scoring match claims each window. On window closure (`chrome.windows.onRemoved`), checks remaining open windows for matching space footprints (≥85% coverage) before unregistering `activeSpaces` mappings to prevent state desync. Handles `GET_TAB_LOCK_STATE` runtime messages and cleans up tab lock session IDs on `chrome.tabs.onRemoved`. Implements frictionless Read Later ingestion via native context menu (`tabbellus-read-later`), global keyboard command (`save-to-read-later` / `Alt+R` / `MacCtrl+R`), and native toolbar Action context menus (`action-capture-window` for capturing window as space with `#3b82f6` badge, `action-save-read-later` for saving active tab with `#22c55e` badge) with 2000ms visual badge confirmations.
- **Zustand (`useUIStore`):**
  - Data: `isSearchOpen`, `isSettingsOpen`, `isHistoryOpen` states.
  - Actions: `setSearchOpen`, `toggleSearch`, `setSettingsOpen`, `toggleSettings`, `setHistoryOpen`, `toggleHistory`.
- **IndexedDB (Dexie):** All application domain data (Spaces, Tabs, Read Later) is stored here for local-first performance and complex querying.

## 6.2 History
- **HistoryDialog** (`src/features/history/HistoryDialog.tsx`):
  - Trigger: History icon in GlobalHeader.
  - Fetches recently closed sessions via `chrome.sessions.getRecentlyClosed`.
  - Real-time updates via `chrome.sessions.onChanged` listener.
  - **Closed Group Visual Folding:** Parses consecutive closed tab sessions with identical timestamps into folded UI entries (`"Closed Group (X tabs)"`) with domain host summaries.
  - **Space Fingerprinting:** Matches closed windows to Spaces via URL comparison (≥80% threshold).
  - **Smart "Focus-If-Open" Routing:**
    - *Window / Space Restoration:* Checks if `matchedSpaceId` is registered in `activeSpaces` and the window is alive. If active, focuses the existing window with `chrome.windows.update`, closes the dialog, and displays a `useToast` feedback notification (`"Focused active space window"`). Otherwise executes standard `chrome.sessions.restore`.
    - *Single Tab Restoration:* Checks if any open browser tab matches the normalized URL. If found, focuses the tab and window via `tabService.focusOrCreate(url)`, closes the dialog, and emits `useToast` feedback (`"Focused open tab"`). Otherwise executes standard session restore.

## 6.3 Active View & Drag-and-Drop Performance
- **ActiveSession** (`src/features/tabs/ActiveSession.tsx`):
  - **Group Closure Snapshot & Full Undo:** Captures group title, color, and child tab URLs before closing. On Undo, recreates tabs (`chrome.tabs.create`), groups them (`chrome.tabs.group`), and restores group title and color (`chrome.tabGroups.update`).
  - **Pragmatic DnD & Virtuoso Integration (Phase 1 & 2):** Headless drag & drop adapter with `closest-edge` target hitbox calculation and solid 2px primary indicator lines (`bg-primary`). Supports whole-group block dragging (`GroupDragPayload`), tri-state group header drop targets (top edge: move above group, bottom edge: move below group, center hit: execute `chrome.tabs.group` to join tab to group), and index offset adjustment math for multi-tab block moves. `TabRow` and `GroupRow` utilize custom `arePropsEqual` comparators evaluating primitive properties (`id`, `url`, `title`, `favicon`, `pinned`, `discarded`, `audible`, `mutedInfo`, `isActive`, `isDragging`, `isCenterHighlighted`, `closestEdge`, `group.id`, `group.title`, `group.color`, `group.collapsed`). Renders flattened discriminated union array `VirtualRow` inside `<Virtuoso>`, enabling 60 FPS scrolling and zero-jank dragging for 1,000+ open tabs.

# TabBellus Project Context Manifest
**Project Version:** 1.2.2

## 1. Database Schema (Dexie.js)
**Database Name:** `TabBellusDB` (Version 3)

### Tables & Indexes
- **`spaces`**: `++id, name, createdAt, deletedAt`
  - `name` (string): User-provided space label.
  - `createdAt` (timestamp): Creation date.
  - `deletedAt` (timestamp, optional): Soft-delete marker.
  - `isPinned` (boolean, optional): User favorite status for 4-tier sorting.
- **`tabs`**: `++id, spaceId, url, order, [spaceId+order]`
  - `spaceId` (number): FK to `spaces`.
  - `url` (string): Full browser URL.
  - `title` (string, optional): Tab title captured at the time.
  - `favicon` (string, optional): Captured icon URL.
  - `order` (number): Relative position in the space.
- **`readLater`**: `++id, url, addedAt, status`
  - `status`: `'unread' | 'read' | 'archived'`

## 2. Core Services
Located in `src/lib/`.

- **`db.ts`** (`TabBellusDB`):
  - `spaces`: `++id, name, createdAt, deletedAt`
  - `tabs`: `++id, spaceId, url, order, [spaceId+order]`
  - `readLater`: `++id, url, title, addedAt, status`
    - `status`: `'unread' | 'read' | 'archived'`
  - **Shared Types**: Exports `SpaceWithTabs` and `SavedTabResult` for data transfer boundary safety.

### **SpaceService**
- `captureCurrentWindow(spaceName)`: Validates current window tabs, filters internal `chrome://` URLs, and performs an atomic transaction to save `Space` and related `Tabs` records.
- `addTabToSpace(spaceId, tab)`: Adds tab to space with duplicate URL checking within target space (throws `DUPLICATE_TAB` error on duplicate URL).
- `createEmptySpace(spaceName)`: Atomically inserts a new empty `Space` into Dexie without capturing current window tabs, separating modal creation from active session captures.
- `restoreSpace(spaceId)`: Fetches ordered tabs and opens them in a new focused Chrome window with staggered loading (tab storm prevention). Wraps `chrome.sidePanel.open` in try/catch and uses declarative `chrome.sidePanel.setOptions` to safely handle gesture token expirations. Emits a decoupled restore event to listeners.
- `createSpaceFromTabs(name, tabs)`: Low-level atomic creation of a Space from an explicit list of tabs. Handles fallback naming for unnamed groups.
- `updateSpaceName(id, newName)`: Updates space name in IndexedDB.
- `toggleSpacePin(spaceId)`: Toggles user pinned status on a space for priority sorting.
- **Database Boundary Encapsulation**: Exposes query providers (`getSpacesOrderedQuery`, `getSpacesNewestFirstQuery`, `getSpaceByIdQuery`, `getTabsForSpaceQuery`, `getSpacesWithTabsQuery`) and CRUD helpers (`softDeleteSpace`, `undoDeleteSpace`, `hardDeleteSpace`, `getSpaceById`, `getTabById`, `deleteTab`, `restoreTab`) to prevent raw database queries or engine handles from leaking into the UI.

### **BookmarkService** (`src/lib/bookmarkService.ts`)
- `getBookmarkTree()`: Safely wraps `chrome.bookmarks.getTree()` with try/catch fallback to return the browser bookmark hierarchy.

### **TabService**
- `focusOrCreate(url)`: Normalizes URLs and checks all open tabs across all windows. If a matching URL is found, it focuses the existing tab; otherwise, it creates a new one.

### **ReadLaterService**
- `addFromTab(tab)`: Saves tab to Read Later database with URL deduplication checking.
- `updateStatus(id, status)`: Updates status of a Read Later item.
- **Database Boundary Encapsulation**: Exposes query providers (`getItemsByStatusQuery`, `getUnreadCountQuery`) and CRUD/lifecycle helpers (`getItemById`, `deleteItem`, `restoreItem`, `getAllItems`) to ensure zero IndexedDB engine leakage into view components.

### **SessionUtils**
- `getRecentSessionId(maxRetries)`: Polling utility with retry backoff to reliably capture recently closed session IDs.
- **Unified Fuzzy Matching Rules**: Exposes `isValidUrl`, `tryParseHost`, and `isFuzzyMatch` to centralize URL validation and fuzzy matching rules for matching closed windows to spaces in both `HistoryDialog.tsx` and the background script.
- **Unit Tests**: Covered by `src/lib/__tests__/sessionUtils.test.ts` (Vitest) to verify subdomains, path suffixes, and SPA route matches.

### **Color Utility**
- **`colors.ts`**: Maps `chrome.tabGroups.ColorEnum` constants to a structured palette including `badge` (solid), `row` (tint), and `border` (guide line) classes for UI consistency.

### **Platform Utility**
- **`platform.ts`**: Browser detection (`isEdge`), safe external link handling (`handleExternalLink`), and `openSupportHub` (extends link with version/browser params).
- **`config/links.ts`**: Centralized `EXTERNAL_LINKS` including Support Hub and Ko-fi.

### **DataService**
- **`dataService.ts`**: Backup & Restore utility.
  - `exportData()`: Downloads all spaces/tabs/read-later as JSON.
  - `exportSpaceAsJson(spaceId)`: Downloads a single space and its tabs as JSON.
  - `importData(file)`: Parses backup, creates new Spaces, maps old IDs to new ones to preserve Tab relationships, and imports data.
  - `clearData()`: Clears all tables.

### **Hooks**
- **`useUndoDelete`** (`src/hooks/useUndoDelete.ts`): Reusable hook for deleting items with "Undo" toast. Decoupled from database engines via functional callback configuration (fetch/delete/restore).
- **`useClipboard`** (`src/hooks/useClipboard.ts`): Hook for copying text with temporary success state.
- **`useIsTruncated`** (`src/hooks/useIsTruncated.ts`): Generic hook using `ResizeObserver` to detect CSS text truncation. Used by `SpaceItem`, `TabRow`, and `GroupRow` for conditional hover tooltips.
- **`useCurrentSpace`** (`src/hooks/useCurrentSpace.ts`): Hook to fetch the currently active `Space` associated with the active window by combining `useAppStore`'s `activeSpaces` mapping and Dexie's live query.
- **`useAddToSpaceAction`** (`src/features/spaces/hooks/useAddToSpaceAction.ts`): Reusable hook to handle space loading and atomic tab additions to spaces, utilized by both hover buttons and context submenus.
- **`useTabLifecycle`** (`src/features/tabs/hooks/useTabLifecycle.ts`): Subscribes to Chrome tab events (`onCreated`, `onUpdated` including `discarded` tab suspension state, `onRemoved`, `onMoved`, `onActivated`, `onAttached`, `onDetached`, `onReplaced`).
- **`useGroupLifecycle`** (`src/features/tabs/hooks/useGroupLifecycle.ts`): Subscribes to Chrome tab group events (`onCreated`, `onUpdated`, `onRemoved`, `onMoved`).

### **UI Primitives**
- **`Toaster`** (`src/components/ui/Toaster.tsx`): Custom toast notification system supporting action undo handlers (`onUndo`) and educational subtitles (`description?: string`).
- **`Tooltip`** (`src/components/ui/Tooltip.tsx`): Radix Tooltip wrappers. Defines `TooltipSimple` (general hover description) and `TooltipOverflow` (truncation-triggered hover details) to encapsulate boilerplate composition.
- **`SmartFallbackIcon`** (`src/components/ui/SmartFallbackIcon.tsx`): Context-aware fallback icon component resolving URL schemes to specific Lucide icons (`chrome://extensions` → Puzzle, `chrome://settings` → Settings, `chrome://`/`edge://` → AppWindow, `file://*.pdf` → FileText, `file://*` → File, Default → Globe).
- **`ContextMenu`** (`src/components/ui/context-menu.tsx`): Radix Context Menu wrappers matching Sleek Developer Minimalist tokens.
- **`Dialog`** (`src/components/ui/Dialog.tsx`): Radix Dialog modal wrapper for empty space creation and settings.
- **`Popover`** (`src/components/ui/popover.tsx`): Radix Popover wrapper for the read-only Global Bookmarks popover.

## 3. Component Map (Atomized)
Located in `src/features/`.
*Each feature folder utilizes the Barrel Pattern (`index.ts`) for clean external imports.*

### **Layout & Navigation**
- **`GlobalHeader`** (`src/sidepanel/components/GlobalHeader.tsx`): Fixed top bar with OmniSearch trigger, history, settings, and Radix Popover Bookmarks trigger (wrapped in `TooltipSimple`).
- **`ActiveSpaceAnchor`** (`src/sidepanel/components/ActiveSpaceAnchor.tsx`): Sticky identity row immediately below `GlobalHeader` that appears when a window is linked to a Space, displaying the Space name.
- **`ViewSwitcher`** (`src/sidepanel/components/ViewSwitcher.tsx`): Segmented control for switching between 'Active', 'Spaces', and 'Read Later' views.

### **Bookmarks Feature**
- **`BookmarkPopoverContent`** (`src/features/bookmarks/BookmarkPopoverContent.tsx`): Read-only recursive tree view for browser bookmarks. Left-click opens URLs in a new active tab (`chrome.tabs.create`).

### **Spaces Feature**
- **`SpaceItem`** (`src/features/spaces/components/SpaceItem.tsx`): 
  - Responsibility: Handles individual space row UI, expansion state, and lifecycle actions (Restore/Focus, Soft-Delete, Undo, Pin).
  - Context Menu: Wrapped in a Radix ContextMenu providing Focus/Restore, Rename, Pin/Unpin Space, Export to JSON, and Delete Space actions.
  - Action Tooltip: Action button wrapped in `TooltipSimple` with dynamic label (`Focus Window` / `Restore Space`).
  - Data: Uses `useLiveQuery` for reactive tab counts and child list rendering.
- **`SpaceList`** (`src/features/spaces/SpaceList.tsx`):
  - Responsibility: Main entry for space visualization using `react-virtuoso` for performance.
  - Sorting: Applies a 4-tier in-memory sort algorithm:
    1. Current Window Active Space
    2. Any Window Active Space
    3. Pinned Spaces
    4. User Sort Preference (Alphabetical A-Z or Newest)
  - Dialog: Integrates custom Radix `<Dialog>` to handle empty space creation via `spaceService.createEmptySpace`.
- **`SpacesToolbar`** (`src/features/spaces/components/SpacesToolbar.tsx`): Memoized local toolbar sitting above SpaceList with Add Space modal trigger, sort order toggle, and expand/collapse all toggle.

### **Tabs Feature**
- **`InteractiveRow`** (`src/features/tabs/components/InteractiveRow.tsx`):
  - Responsibility: Shared compound layout primitive using `React.forwardRef` that centralizes hover effects, size variations, truncation checks (`block w-full`), tooltip wiring, and hidden actions trays. Suppresses native title attributes when `TooltipSimple` is active.
- **`TabRow`** (`src/features/tabs/components/TabRow.tsx`):
  - Responsibility: Individual tab list item. Composes `<InteractiveRow size="md">` with normalized `data: RowTabData` for native type-safety.
  - Favicon: Uses `SmartFallbackIcon` for URL-aware fallback rendering (`chrome://`, `file://`, `pdf`).
  - Context Menu: Wrapped in a Radix ContextMenu offering Pin/Unpin, Mute/Unmute, Duplicate, Suspend, Copy URL, Save to Space (submenu), and Read Later.
  - Action Tooltips: Action buttons wrapped in `TooltipSimple` (`Save to Space`, `Read Later`, `Delete Tab from Space`, `Close Tab`).
- **`GroupRow`** (`src/features/tabs/components/GroupRow.tsx`):
  - Responsibility: Visual header for Chrome Tab Groups. Composes `<InteractiveRow size="sm">` and encapsulates group children left-border styling container inside `GroupRow.Children`.
- **`ActiveSession`** (`src/features/tabs/ActiveSession.tsx`):
  - Responsibility: Real-time "Active Tree" visualization. Features compacted 28px single-row capture header `[ Input ] [ X Tabs ] [ Save ]`.
  - Toolbar: Integrates `ActiveToolbar` with New Tab (`+`), Back, Forward, Reload, tab sorting dropdown, and Close Unpinned tabs with in-memory snapshot Undo toast.
  - Logic: Configuration-driven rendering driven by a declarative Render Strategy Registry (`ACTIVE_SESSION_RENDERERS`).
  - **Drag & Drop:** Wrapped in `<DragDropContext>` from `@hello-pangea/dnd`.
- **`ActiveToolbar`** (`src/features/tabs/components/ActiveToolbar.tsx`): Memoized context-aware toolbar for active session management.

### **Read Later Feature**
- **`ReadLaterList`** (`src/features/read-later/ReadLaterList.tsx`):
  - Responsibility: Inbox queue for saved links with status filtering (unread/read/archived).
  - Context Menu: Wrapped in Radix ContextMenu offering Open, Copy URL, Mark as Read/Unread, and Delete.
  - Action Tooltips: Checkbox and delete action wrapped in `TooltipSimple`.
- **`ReadLaterToolbar`** (`src/features/read-later/components/ReadLaterToolbar.tsx`): Memoized local toolbar with bulk actions (`Mark All as Read`, `Clear All Read`).

## 4. State Management
- **Zustand (`useAppStore`):**
  - Persistence: Persisted to **Chrome Storage Local** using a custom adapter.
  - Theme Management: Implemented in `src/sidepanel/index.tsx` via `useEffect` to sync system/selected theme ('light'|'dark'|'system') with the root `<html>` element.
  - Data: UI state like `activeView` and hydration status.
  - **Active Spaces Bridge:** `activeSpaces` (ephemeral) maps `SpaceID -> WindowID` for tracking open spaces. Enforces strict 1-to-1 Window-to-Space binding by removing existing space mappings for a target `windowId` before registering a new space. Synced across windows via `chrome.storage.session`. Subscribes to `spaceService.onRestore` events to dynamically register active spaces upon restoration.
- **Background Worker (`src/background/index.ts`):** Listens to tab updates (`onCreated`, `onUpdated`, `onMoved`, `onAttached`, `onDetached`, `onReplaced`, etc.) and debounces updates to IndexedDB continuously when the active window corresponds to a known tracked space. Uses `chrome.alarms` for background sync flushing (`sync-flush-${windowId}`). Performs 1-to-1 Best Match fingerprinting on startup (`auditActiveSpacesOnStartup`), ranking spaces by score/coverage and tab length differences so the single highest-scoring match claims each window. Cleans up `activeSpaces` state when the tracked window closes.
- **Zustand (`useUIStore`):**
  - Data: `isSearchOpen`, `isSettingsOpen`, `isHistoryOpen` states.
  - Actions: `setSearchOpen`, `toggleSearch`, `setSettingsOpen`, `toggleSettings`, `setHistoryOpen`, `toggleHistory`.
- **IndexedDB (Dexie):** All application domain data (Spaces, Tabs, Read Later) is stored here for local-first performance and complex querying.

## 5.2 History
- **HistoryDialog** (`src/features/history/HistoryDialog.tsx`):
  - Trigger: History icon in GlobalHeader.
  - Fetches recently closed sessions via `chrome.sessions.getRecentlyClosed`.
  - Real-time updates via `chrome.sessions.onChanged` listener.
  - **Closed Group Visual Folding:** Parses consecutive closed tab sessions with identical timestamps into folded UI entries (`"Closed Group (X tabs)"`) with domain host summaries.
  - **Space Fingerprinting:** Matches closed windows to Spaces via URL comparison (≥80% threshold).
  - **Restore:** Sequential restore via `chrome.sessions.restore`. Re-links matched spaces via `registerActiveSpace`.

---

## 5.3 Active View & Drag-and-Drop Performance
- **ActiveSession** (`src/features/tabs/ActiveSession.tsx`):
  - **Group Closure Snapshot & Full Undo:** Captures group title, color, and child tab URLs before closing. On Undo, recreates tabs (`chrome.tabs.create`), groups them (`chrome.tabs.group`), and restores group title and color (`chrome.tabGroups.update`).
  - **DnD Re-render Optimization:** `TabRow` and `GroupRow` utilize custom `arePropsEqual` comparators in `React.memo` evaluating primitive properties (`id`, `url`, `title`, `favicon`, `pinned`, `discarded`, `audible`, `mutedInfo`, `isActive`, `isDragging`, `group.id`, `group.title`, `group.color`, `group.collapsed`). Sub-renderers (`TabRowRenderer`, `GroupBlockRenderer`) are memoized with `memo()`, and action handlers are stabilized with `useCallback()`, reducing drag re-render latency from 183ms to under 2ms.

## 6. Engineering Rules & Protocols
*Strict adherence required for all code modifications.*

### **Logic Mapping & Preservation**
1. **Functional Inventory:** Before modifying a file, identify and preserve existing validation, error handling, and edge-case logic.
2. **Spirit Rule:** Carry over all safety checks, warnings, and filters during refactors unless explicitly instructed otherwise.

### **Safe-Edit Protocol**
1. **Unique Anchors:** Ensure search strings for edits are unique to the intended block.
2. **Atomic Changes:** Surgical patches are preferred over full-file rewrites.
3. **Regression Prevention:** Verify that "old" features (e.g., Delete Undo timers, empty states) still exist after an edit.

### **Technology Constraints**
1. **MVS (Minimum Viable Solution):** Avoid over-engineering.
2. **Local-First:** Prioritize database performance and offline reliability.
3. **Aesthetics:** Maintain premium shadcn/ui visual standards using semantic tokens.

- **Release Pipeline:** The `npm run release` script generates a production build, scans the `dist` folder for "localhost" to prevent accidental developer API deployment, automatically deletes `dist` if validation fails, and packages the result into a clean zip via PowerShell `Compress-Archive`.

# TabBellus Project Context Manifest
**Project Version:** 1.2.2 — Chrome Extension (Manifest V3) tab and workspace manager with Free core and isolated Pro subsystem.

---

## 1. MANDATORY CUSTOM ABSTRACTIONS
To prevent context amnesia, code duplication, and inconsistent UI patterns, developers and AI agents MUST strictly use these established project abstractions instead of native browser fallbacks or raw primitives:

- **`useToast`** (`@/components/ui/Toaster`): Use for all user feedback, operation status, and undo notifications. NEVER use native `alert()`, `confirm()`, or unstyled inline errors.
- **`useClipboard`** (`@/hooks/useClipboard`): Use for all clipboard copying (`copy(text)`). NEVER call `navigator.clipboard.writeText()` directly.
- **`InteractiveRow`** (`@/features/tabs/components/InteractiveRow`): Compound row layout (`InteractiveRow.Leading`, `Title`, `Actions`, `Action`). NEVER build custom flex containers or list item rows from raw `<div>`s for tabs or spaces.
- **`SmartFallbackIcon`** (`@/components/ui/SmartFallbackIcon`): 3-tier favicon resolution cascade (native URL -> Chromium `_favicon` cache -> Lucide icon/Globe). NEVER render raw unhandled `<img>` for favicons.
- **`TooltipSimple` & `TooltipOverflow`** (`@/components/ui/Tooltip`): Use `TooltipSimple` for buttons/actions and `TooltipOverflow` with `useIsTruncated` for truncated text. NEVER use raw HTML `title="..."` attributes on main text elements.
- **`ContextMenu` & `DropdownMenu`** (`@/components/ui/context-menu`, `@/components/ui/dropdown-menu`): Styled Radix primitives. NEVER build custom fixed-position context menu divs or raw browser context listeners.
- **`spaceService`, `tabService`, `readLaterService`** (`@/lib/`): Encapsulated domain service layer. NEVER write raw Dexie queries (`db.spaces.*`, `db.tabs.*`, `db.readLater.*`) directly inside React UI components.
- **`useUndoDelete`** (`@/hooks/useUndoDelete`): Wrapped deletion flow with automated undo toast notification. NEVER execute irreversible destructive deletions in UI components without undo opportunity.
- **`platform.ts`** (`@/lib/platform.ts`): Helpers (`handleExternalLink`, `openSupportHub`, `openAppearanceSettings`, `getReadLaterShortcutText`, `formatKeyBinding`). NEVER call raw `window.open` or unvalidated `chrome.tabs.create` for external/support links.
- **Owned UI Primitives** (`src/components/ui/*`): Owned source code (never overwrite via generators) with explicit high-contrast state classes; see `.agents/rules/ui.md`. NEVER use structural layout tokens (`bg-input`, `border-input`, `bg-muted`) that collapse on OLED dark or pure white themes.
- **`<FeatureGate>` & Registry Contracts** (`@/core/`): Declarative tier gating (`<FeatureGate requires="pro" fallback={...}>`) and dynamic extension slots. NEVER write proprietary Pro business logic or scattered `if (isPro)` conditionals inside Free view components.

## 2. Database Schema (Dexie.js: `TabBellusDB` v5)
Defined in `src/lib/db.ts`. Domain data is local-first in IndexedDB; never queried directly from UI components.

- **`spaces`**: `++id, &uuid, name, createdAt, updatedAt, deletedAt`
  - `id` (number, auto-increment PK), `uuid` (string, immutable unique cross-device UUID), `name` (string), `createdAt` (number), `updatedAt` (number, LWW sync timestamp), `deletedAt` (number, soft-delete tombstone), `isPinned` (boolean, optional), `color` (string, optional Chrome color tag).
- **`tabs`**: `++id, spaceId, url, order, deletedAt, [spaceId+order]`
  - `id` (number, auto-increment PK), `spaceId` (number, FK -> `spaces.id`), `url` (string, normalized via `normalizeTabUrl`), `title` (string, optional), `favicon` (string, optional), `order` (number), `createdAt` (number, optional tab birth timestamp), `updatedAt` (number, optional LWW timestamp), `deletedAt` (number, soft-delete tombstone).
- **`readLater`**: `++id, url, title, addedAt, status, deletedAt`
  - `id` (number, auto-increment PK), `url` (string), `title` (string, optional), `favicon` (string, optional), `addedAt` (number), `status` (`'unread' | 'read' | 'archived'`), `deletedAt` (number, soft-delete tombstone), `updatedAt` (number, optional LWW status timestamp).
- **Shared Types**: `Space`, `Tab`, `ReadLaterItem`, `SpaceWithTabs`, `SavedTabResult`.

## 3. Core Architecture & Module Map

## 5. State Management & Storage Mapping

### Zustand Stores
- **`useAppStore`** (`src/store/appStore.ts`):
  - `settings`: `AppSettings` (`theme`, `badgeMode`, `showDomain`, `readLaterOpenBehavior`, `readLaterAutoArchive`, `autoDiscardInterval`, `spaceRestoreTrigger`, `duplicateTabBehavior`, `settingsUpdatedAt`). Persisted to `chrome.storage.local` under key `tabbellus-settings`.
  - `activeView`: Current sidepanel view (`'active' | 'spaces' | 'read-later'`). Ephemeral.
  - `activeSpaces`: Mapping `Record<spaceId, windowId>` tracking active space window bindings. Synced across windows via `chrome.storage.session`.
  - `recentSearches`: Recent query string array.
- **`useUIStore`** (`src/store/uiStore.ts`):
  - Ephemeral dialog open states: `isSearchOpen`, `isSettingsOpen`, `isHistoryOpen` and toggles.
- **`useTabLockStore`** (`src/features/tabs/store/tabLockStore.ts`):
  - `lockedTabIds`: Protected tabs array synced with `chrome.storage.session` (`lockedTabIds`). Enforced by content script `src/content/lockGuard.ts` on `<all_urls>`.

### Storage Keys & Quotas
- `chrome.storage.local`:
  - `tabbellus-settings`: Zustand persisted application preferences.
- `chrome.storage.session`:
  - `tabbellus_active_spaces`: Ephemeral window-to-space ID bindings.
  - `lockedTabIds`: Ephemeral tab protection IDs.
  - `tabbellus_window_restoring_${windowId}`: 3500ms temporary restoration lock preventing premature tab tombstoning.
  - `tabbellus_vault_session`: Ephemeral PBKDF2 derived encryption key for active E2EE session.
- `chrome.storage.sync` (Pro only, with local fallback):
  - `tabbellus_tab_rules`: Tab automation rules JSON (strictly bounded under 8KB sync quota).
- `IndexedDB` (`TabBellusDB`):
  - Domain records for `spaces`, `tabs`, and `readLater`.
